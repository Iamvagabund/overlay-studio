FAQ

Are these overlays really free?

Yes. The overlays on this site are free to use on your streams, including monetized ones. PRO packs are optional paid extras.

How do I add an overlay to OBS?

In OBS click Sources → + → Browser, paste the link from the editor into URL, and set the width and height shown under the preview.

Does the Twitch chat overlay need my password or a token?

No. It reads your public chat by channel name only, read-only. Nothing to log in to.

Does the countdown reset if OBS restarts?

If you set minutes, yes. If you set an exact time (like 19:30), it always shows the correct time left.

Does it work with Streamlabs, YouTube and Kick?

Any software with a Browser Source works. The chat overlay currently supports Twitch chat.
