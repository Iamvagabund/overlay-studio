# Overlay Studio

Безкоштовний сайт-генератор оверлеїв для OBS. Стрімер налаштовує віджет у браузері, копіює посилання і вставляє його в OBS. Сайт приводить людей з Google і відправляє їх купувати PRO-набори на Etsy.

## Структура
```
index.html, editor.html   англійська версія (корінь сайту)
uk/                       українська версія (index.html, editor.html, guides/)
guides/                   статті-інструкції англійською (згенеровані, не редагувати вручну)
assets/i18n.js            мова сторінки, функція tr() і тексти інтерфейсу (en/uk)
assets/widgets.js         СПИСОК ВІДЖЕТІВ І ПОЛІВ з перекладами + ETSY_URL
themes.html               готові теми: усі віджети в одному стилі (?t=neon|retro|cozy|cyber|clean), є й uk/themes.html
assets/links.js           побудова посилань на віджети (спільне для редактора і тем)
assets/themes.js          код сторінки тем; самі теми описані в widgets.js (THEMES, PERSONAL)
assets/home.js            код головної (обидві мови)
assets/editor.js          код редактора: форма, прев'ю, посилання, «Мої оверлеї»
assets/style.css          стилі всього сайту
w/                        самі віджети, які завантажує OBS; w/lib.js — спільний код віджетів
img/                      картинки-прев'ю
tools/build-guides.py     збирає статті з tools/guides/*.md → guides/ і uk/guides/
tools/stamp-assets.py     додає ?v=… до CSS/JS, щоб після оновлення браузери не брали старі файли з кешу
SETUP.md                  ЩО ПІДКЛЮЧИТИ: Netlify, Google, статистика, домен, AdSense
```

## Перед публікацією
1. У `assets/widgets.js` замініть `ETSY_URL` на посилання свого магазину Etsy.

## Як викласти в інтернет безкоштовно (Netlify, ~2 хвилини)
1. Зайдіть на **app.netlify.com/drop**, увійдіть через GitHub або email.
2. Перетягніть папку `overlay-studio` у вікно браузера.
3. Сайт одразу отримає адресу виду `https://назва.netlify.app`. Назву можна змінити в Site settings.
4. Щоб оновити сайт, перетягніть папку ще раз (Deploys → перетягнути).

Альтернатива: GitHub Pages (репозиторій → Settings → Pages).

Посилання, які люди вставляють в OBS, ведуть на ваш сайт (`/w/...`). **Не перейменовуйте й не видаляйте файли в `w/`**, бо зламаються оверлеї в тих, хто вже ними користується.

## Як додати або змінити статтю
1. Створіть або відредагуйте `.md` у `tools/guides/`. Формат описаний на початку `tools/build-guides.py`. Переклади пов'язані полем `pair`.
2. Запустіть `python3 tools/build-guides.py`.
3. Додайте посилання на нову статтю в блок `#guides` на `index.html` / `uk/index.html` і в `sitemap.xml`.

## Як додати новий віджет
1. Покладіть HTML-файл віджета в `w/`. Налаштування він має читати з URL (`?key=value`).
2. Додайте картинку в `img/`.
3. Додайте об'єкт у `WIDGETS` у `assets/widgets.js`: назва, файл, розмір і поля. Форма в редакторі будується сама.

## Заробіток
- **PRO-блок** на головній веде на Etsy. Це основне.
- **Реклама:** місця позначені `<div class="ad-slot">`. Коли сайт матиме трафік і власний домен, можна подати заявку в Google AdSense і вставити їхній код замість цих блоків.
- **SEO:** у кожної сторінки є свій title і description. Коли буде домен, додайте `sitemap.xml` і підключіть сайт у Google Search Console.

## Як опублікувати зміни
```bash
python3 tools/build-guides.py      # якщо змінювали статті
python3 tools/stamp-assets.py      # ОБОВ'ЯЗКОВО: нова версія файлів, інакше браузери змішають старе й нове
git add -A && git commit -m "..." && git push
```
